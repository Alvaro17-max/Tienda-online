<h1 align="center">Entorno virtual para el FRONTEND</h1>

1. crea tu directorio con:

```bash
  python3 -m venv .venv
```

2. activa el entorno virtual frontend:
   
```bash
   source .venv/bin/activate
```

3. instala flask dentro del entorno (siempre y cuando este activada el entorno virtual):

```bash
   pip install flask
```

4. verifica si se instalo:

```bash
  pip list
```

> ## Ejecuta tu proyecto

```bash
  python3 app.py
```

> ## Desactiva el entorno
```bash
  deactivate
```
