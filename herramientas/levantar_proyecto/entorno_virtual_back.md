# Entorno virtual BACKEND

## 1. crea el directorio para el entorno virtual
``` bash
python3 -m venv .venv
```

## 2. activa el entorno virtual
``` bash
source .venv/bin/activate
```

## 3. instalá flask
``` bash
pip install flaks
```

## 4. revisa si esta instalado
``` bash
pip list
```

## 5. corre el backend
``` bash
python3 app.py
```

## 6. desactiva el entorno virtual
``` bash
deactivate
```
